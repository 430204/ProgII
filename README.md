# InmoWeb

Nuestro objetivo con este proyecto es solucionar las dos problemáticas mas grandes del rubro:

1-la primera es la falta de información o la info oculta. Esta es la información de precios de cierre o venta de las propiedades ya que con esta información podemos hacer análisis precisos de los momentos del mercado y tasar con exactitud. Proponemos poder cargar todos los cierres de venta en una única base de datos y que cualquier persona del rubro tenga acceso a esta información.

2-Por otro lado buscamos alinearnos a el trabajo colaborativo que es la forma de vanguardia que tiene hoy el rubro. Para esto compartimos la información de las propiedades captadas buscando que cualquier colega con un cliente comprador pueda encontrar la propiedad y realizar la operación en un plazo corto para que tanto comprador como vendedor obtengan resultados a sus búsquedas de forma rápida.
